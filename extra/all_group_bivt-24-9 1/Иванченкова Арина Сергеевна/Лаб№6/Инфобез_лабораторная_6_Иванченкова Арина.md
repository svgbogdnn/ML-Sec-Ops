# 5 разнотипных секретов
 
## Первый
  1. Путь к секрету: .travis.yml /
  строка 
```
+      secure: [93mpJOLBnl6427PcVg/tVy/qB18JC7b8cKpffau+IP0pjdSt7KUfBdBY3QuJ7mrM65zRoVILzggLckaew2PlRmYQRdumyWlyRn44XiJ9KO4n6Bsufbz+ictB4ggtozpp9+I9IIUh1TmqypL9lhkX2ONM9dSHmyblYpAAgMuYSK8FYc=[0m
```

2. Что это может быть и почему это секрет: Это может быть Personal Access Token GitHub. Если такой токен попадёт к злоумышленнику, то он сможет выполнять различные действия от имени хозяина токена(пуши, переписывание истории репозитория и т.д.).
3.  Как можно устранить:  Отозвать токен -> создать новый токен с минимальными правами и обновить его в настройках ci/cd -> почистить историю git
4.  Как хранить : использовать github actions, токен будет храниться в специальном разделе репозитория в зашифрованном виде. Никогда не комитить токены, давать минимальные права, устанавливать срок действия токена.

## Третий
1. Где хранится: webgoat-integration-tests/src/test/java/org/owasp/webgoat/CSRFTest.java
   строка:
```
"<input type=\"hidden\" name=\"username\" value=\"csrf-USERNAME\"/>\n" +
-            "<input type=\"hidden\" name=\"password\" value=\"password\"/>\n" +
-            "<input type=\"hidden\" name=\"matchingPassword\" value=\"password\"/>\n" +

```

```
params.put("username", "csrf-"+getWebgoatUser());
params.put("password","password");
```
2. Что это может быть и почему это секрет:  это имя пользователя и пароль в явном виде. Если злоумышленник получит эти данные, он сможет получить доступ к аккаунту пользователя.
3. Как устранить: почистить историю git-> поменять пароль везде, где он использовался
4. где хранить:  в переменных окружениях(не комитятся)

2. Что это может быть и почему это секрет: Это API-ключ, который используется для интеграции с внешним сервисом codacy. Получив API-ключ, злоумышленник может собирать конфиденциальную информацию о проекте.

4. как хранить:  в github actions, в переменных окружениях. Если проект не для прода, то можно локально, предварительно закинув json c ключом в .gitignore
