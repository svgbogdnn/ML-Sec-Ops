# Часть I. Анализ CVE

## CVE-2024-21626  
Уязвимость в контейнерном рантайме runc позволяет выход из контейнера и доступ к хосту.  
Причина: ошибки изоляции контейнеров.  
OWASP: API8 Security Misconfiguration  

## CVE-2024-24706  
Обход аутентификации в Grafana API.  
Причина: ошибки проверки токенов.  
OWASP: API2 Broken Authentication  

## CVE-2024-34351  
Mass Assignment в Spring API.  
Причина: отсутствие валидации входных данных.  
OWASP: API6 Mass Assignment

## Найденная уязвимость

Endpoint:
/users/v1/_debug

Возвращает:
- username
- email
- password
- admin

---

## Уязвимость
API3: Excessive Data Exposure

---

## Причина
Отсутствие фильтрации данных API ответа

---

## Последствия
- утечка паролей
- компрометация admin
- раскрытие данных пользователей

---

## Меры защиты
- убрать password из ответов
- DTO модели
- RBAC доступ
- отключить debug endpoint

---

## Вывод
Обнаружена критическая уязвимость Excessive Data Exposure
