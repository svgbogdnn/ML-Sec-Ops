Отчёт по CVE за 2021 год: XSS в PHP компонентах
=================================================

По данным NVD (nvd.nist.gov), за 2021 год было опубликовано более 4000 CVE,
содержащих XSS уязвимости в PHP компонентах. Это показывает, что даже
хорошо известная и давно изученная уязвимость продолжает массово встречаться.


CVE-1: CVE-2021-24233
======================
Продукт: Cooked Pro (плагин для WordPress, написан на PHP)
CVSS Score: 6.1 (Medium)
Тип: Reflected XSS

Назначение компонента:
Cooked Pro это плагин для WordPress, предназначенный для публикации кулинарных
рецептов на сайте. Он позволяет создавать красиво оформленные страницы рецептов
с ингредиентами, шагами приготовления, временем готовки, фотографиями и
рейтингами. Плагин широко используется кулинарными блогами и сайтами с едой.

Описание уязвимости:
В версиях до 1.7.5.6 плагин некорректно обрабатывал пользовательский ввод
перед выводом его обратно на страницу в виде атрибута HTML. Из-за отсутствия
санитизации злоумышленник мог передать вредоносный JavaScript в параметрах
запроса, и браузер жертвы выполнял этот скрипт при открытии специально
сформированной ссылки. Атака не требовала авторизации.

Причина: отсутствие экранирования пользовательского ввода при выводе в HTML.

Источник: https://nvd.nist.gov/vuln/detail/CVE-2021-24233


CVE-2: CVE-2021-38341
======================
Продукт: WooCommerce Payment Gateway Per Category (плагин для WordPress, PHP)
CVSS Score: 6.1 (Medium)
Тип: Reflected XSS

Назначение компонента:
Это плагин для интернет-магазинов на WordPress с WooCommerce. Он позволяет
настраивать разные способы оплаты для разных категорий товаров. Например,
для электроники можно включить оплату картой, а для цифровых товаров только
PayPal. Используется владельцами интернет-магазинов для гибкой настройки
платёжных шлюзов.

Описание уязвимости:
В версиях до 2.0.10 в файле plugin_settings.php значение $_SERVER["PHP_SELF"]
(путь к текущему скрипту) напрямую подставлялось в атрибут action HTML-формы
без экранирования. Злоумышленник мог сформировать URL вида:
/wp-admin/admin.php/"><script>alert(1)</script>
и при открытии страницы настроек плагина скрипт выполнялся в браузере жертвы.

Причина: прямое использование $_SERVER["PHP_SELF"] в HTML без htmlspecialchars().

Источник: https://nvd.nist.gov/vuln/detail/CVE-2021-38341


CVE-3: CVE-2021-26230
======================
Продукт: CASAP Automated Enrollment System v1.0 (PHP веб-приложение)
CVSS Score: 6.1 (Medium)
Тип: Stored/Reflected XSS

Описание уязвимости:
В системе автоматизации записи студентов на PHP злоумышленник мог передать
произвольный JavaScript через поля с информацией о пользователе в файл
save_user.php. Данные сохранялись или выводились без экранирования.

Причина: отсутствие валидации и санитизации входных данных перед сохранением
и выводом.

Источник: https://nvd.nist.gov/vuln/detail/CVE-2021-26230


Итог:
=====
За 2021 год в NVD зафиксировано более 4000 CVE с XSS в PHP компонентах.
Это подтверждает, что несмотря на многолетнюю известность уязвимости,
разработчики продолжают допускать одни и те же ошибки: отсутствие
экранирования вывода и валидации ввода.
