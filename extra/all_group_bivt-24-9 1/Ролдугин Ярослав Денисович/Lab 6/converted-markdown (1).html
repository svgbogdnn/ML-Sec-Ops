Часть 2

  1. Создадим простейший Dockerfile с базовыми настройками безопасности
# Фиксируем конкретный тег для обеспечения стабильности сборки
FROM alpine:3.19


# Обновляем пакеты сразу при сборке, чтобы закрыть известные CVE
RUN apk update && apk upgrade --no-cache


# Создаём системную группу и пользователя без пароля и логин-шелла для безопасности
RUN addgroup -S -g 1001 appgroup && \
    adduser -S -u 1001 -G appgroup appuser
  
# Берем только необходимые файлы для приложения, чтобы минимизировать размер образа
WORKDIR /app

# Переключаемся на непривилегированного пользователя
USER felicuss

EXPOSE 8080

CMD ["sh"]
  1. Далее контейнер запустим
docker run -it --rm secure-alpine sh

Внутри нашего контейнера выполним

whoami

Видим

felicuss

Отсюда можем понять

  2. 0 уязвимостей, т.к образ минимальный Понимаем, что такой образ не надо использовать, потому что новые CVE не будут ложиться в базу
