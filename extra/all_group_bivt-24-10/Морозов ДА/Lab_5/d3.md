# Вывод по части 3

Образ `my-secure-alpine` был просканирован с помощью Trivy. Сканер определил ОС как Alpine Linux версии 3.23.4 и проверил 16 установленных пакетов.

По результатам проверки уязвимости не обнаружены: `Vulnerabilities: 0`. Это означает, что в текущей базе Trivy для данного образа нет известных CVE.

Образ можно считать безопасным для использования/

При этом отсутствие уязвимостей не гарантирует полной безопасности, поэтому дополнительно используются ограничения при запуске контейнера: отключение capabilities, отключение сети и запрет повышения привилегий.
