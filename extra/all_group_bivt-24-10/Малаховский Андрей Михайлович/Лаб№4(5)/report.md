### Фрагмент кода 2
```python
from flask_wtf import Form  
from wtforms import TextField

class LoginForm(Form):  
    username = TextField('username')  
    password = TextField('password')
```

**Недостаток**  
Поле `password` объявлено как обычное текстовое поле. Это означает, что пароль будет вводиться и отображаться как обычный текст, что небезопасно. 

**Рекомендации по устранению**  
Для пароля нужно использовать специальное поле `PasswordField`, чтобы введенные символы не отображались открыто. Также следует добавить проверки: обязательность заполнения, минимальную длину пароля и, при необходимости, другие ограничения.

### 1. Какие наиболее распространенные атаки предотвращает Django?

Django помогает защищаться от следующих распространенных атак:  
- **XSS** - шаблоны Django по умолчанию экранируют HTML-символы.  
- **CSRF** - используются специальные CSRF-токены для защиты форм и POST-запросов.  
- **SQL-инъекции** - при работе через ORM запросы формируются безопаснее, без прямой подстановки строк.  
- **Clickjacking** - можно использовать встроенную защиту через заголовок X-Frame-Options.  
- **Атаки через поддельный Host-заголовок** - ограничиваются с помощью настройки ALLOWED_HOSTS.  

При этом защита работает только в том случае, если разработчик не отключает встроенные механизмы безопасности.

### 2. Описать, как устроено управление пользовательскими сессиями в Django?  
  
Управление сессиями в Django устроено так:  
  
- после входа пользователя создается сессия;  
- браузеру обычно передается cookie с идентификатором сессии;  
- данные сессии чаще всего хранятся на сервере, обычно в базе данных;  
- доступ к данным выполняется через request.session;  
- при входе пользователя Django может обновлять ключ сессии для повышения безопасности;  
- можно настроить срок жизни сессии, а также параметры cookie: HttpOnly, Secure, SameSite.  
  
Таким образом, Django предоставляет готовый механизм хранения и обработки пользовательских сессий, который можно дополнительно настраивать под требования безопасности.
