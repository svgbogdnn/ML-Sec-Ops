# Часть 1
#### 1) CVE‑2021‑24545 : HTML Author Bio WordPress Plugin
https://nvd.nist.gov/vuln/detail/CVE-2021-24545

HTML Author Bio - плагин для CMS WordPress, написанный на PHP, который добавляет на сайт настраиваемый HTML‑блок профиля автора (биографию, ссылки, оформление) и отображает его на страницах записей. Уязвимость связана с обработкой поля description на странице /wp-admin/profile.php: введённые данные не проходят достаточной фильтрации и экранирования, поэтому атакующий может сохранить в этом поле произвольный HTML/JavaScript‑код. При выводе блока “об авторе” на странице записи этот код встраивается в HTML‑страницу и выполняется в браузере посетителя, что приводит к stored XSS и позволяет атакующему выполнять действия в контексте сессии жертвы или похищать её данные.

#### 2) CVE‑2021‑41169 : Sulu (Symfony‑based PHP CMS)
https://nvd.nist.gov/vuln/detail/CVE-2021-41169

Sulu - это система управления контентом на PHP, построенная на базе фреймворка Symfony.В рамках CVE‑2021‑41169 некоторые поля, редактируемые через админку Sulu, выводятся без корректного HTML‑экранирования, что позволяет злоумышленнику, обладающему правами на изменение контента, внедрить в них JavaScript‑код. При последующем открытии страницы с этим контентом в интерфейсе Sulu внедрённый скрипт выполняется в браузере пользователя (stored XSS), что даёт атакующему возможность выполнять действия от имени жертвы в административной панели или похищать данные её сессии.

# Часть 2
Зашел на http://localhost:8080 , там две ссылки на http://localhost:8080/XSS-1/ и http://localhost:8080/index.php

На http://localhost:8080/XSS-1/ в окно comment? ввел `<script>alert('Опасность')</script>` и нажал Save Data
После этого высветилось окно с текстом Опасность. При перегрузке станицы также высвечивалось это окошко
Получается, что код добавился в код страницы. .То есть при каждом обновлении скрипты выполнятся заново

Эта уязвимость называется Межсайтовый скриптинг (Cross-Site Scripting,XSS).
Приложение принимает данные от пользователя без нужной проверки. В результате браузер интерпретирует текст не как обычную строку, а как javascript код, и запускает его.

Меры предотвращения:
1. Экранирование спецсимволов
2. Санитизация HTML
3. Не вставлять ввод напрямую в код страницы
