# ЛР 5
## Базовая настройка безопасности docker-контейнера
### Часть 1
1. Выведем не докер-образы, которые есть на моем компьютере с помощью команды docker image ls
2. Выберем для теста образ из предыдущей лабы ket9/otus-devsecops-xss 
3. Проверяем текущего пользователя хоста командой whoami [вывод команды](./image1.png)
4. Запускаем контейнер и заходим в shell командой ```docker run -it ket9/otus-devsecops-xss sh``` и сразу введем команду ```whoami```
[результат](./image_2.png)

Контейнер по умолчанию запускается от имени root-пользователя

### Часть 2 Безопасный Dockerfile
1. Заполняем простой [Dockerfile](./Dockerfile)

2. Командой 
```docker build -t task-2 .``` собираем контейнер и командой ```docker run -it task-2 sh
whoami``` запускаем его и смотрим пользователя хоста 

команда whoami не прошла, тогда используем команду id 

[результат](./image_3.png) - контейнер запускается от appuser 

### Часть 3
Протестируем образ с помощью Trivy
1. Установка ```brew install trivy```
2. Просканируем образ ```trivy image task-2```
