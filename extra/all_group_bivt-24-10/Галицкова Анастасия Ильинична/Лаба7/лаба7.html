Обнаруженные уязвимости и план митигации

HIGH Cleartext HTTP трафик CWE-319
Описание
Приложение разрешает передачу данных по незашифрованному HTTP. Злоумышленник в той же сети может перехватить и модифицировать трафик (MITM-атака).
Затронутые домены
Домены Unity Ads и других рекламных SDK настроены без принудительного HTTPS в network_security_config.xml.
Митигация
Установить android:usesCleartextTraffic="false" в манифесте. В network_security_config.xml явно указать cleartextTrafficPermitted="false" для всех доменов. Все SDK обновить до версий с поддержкой HTTPS.
HIGH Слабый алгоритм подписи сертификата — SHA1withRSA + RSA 1024 бит CWE-327
Описание
Приложение подписано алгоритмом SHA1withRSA. SHA-1 имеет известные коллизии и считается устаревшим. Размер ключа 1024 бит недостаточен по современным стандартам.
Риск
Теоретическая возможность подделки подписи и распространения вредоносной версии приложения от имени разработчика.
Митигация
Перевыпустить сертификат подписи с алгоритмом SHA256withRSA и ключом минимум 2048 бит. Включить v3/v4 подпись при сборке. Обновить keystore и переподписать приложение.
HIGH Некорректная настройка App Links (assetlinks.json) CWE-20
Описание
Файл верификации App Links assetlinks.json не найден или некорректно настроен для доменов SubwaySurfers.sng.link и subwaysurfers.sng.link.
Риск
Вредоносное приложение может перехватывать deep-link URL, предназначенные для Subway Surfers — фишинг, кража токенов авторизации.
Митигация
Разместить корректный файл /.well-known/assetlinks.json на всех доменах, указанных в манифесте как App Links. Верифицировать через Google Digital Asset Links API. Добавить android:autoVerify="true" в intent-filter.
HIGH Поддержка устаревших версий Android (minSdk=23) CWE-1104
Описание
Приложение может быть установлено на Android 6.0 (API 23), которая содержит множество неисправленных уязвимостей и не получает обновлений безопасности от Google.
Риск
Пользователи на старых Android подвержены эксплойтам уровня ОС, которые приложение не может компенсировать.
Митигация
Поднять minSdkVersion до 29 (Android 10) в соответствии с рекомендациями Google. Это исключит устройства, не получающие обновлений безопасности.
HIGH Использование слабого шифрования — ECB режим и MD5/SHA-1 CWE-327 / CWE-328
Описание
В коде найдено использование AES в режиме ECB (одинаковые блоки открытого текста дают одинаковый шифротекст), а также хэш-функций MD5 и SHA-1 в криптографических целях.
Файлы
Преимущественно в рекламных SDK: com/ironsource/, com/fyber/, com/mbridge/, com/unity3d/
Митигация
Заменить ECB на AES/GCM или AES/CBC с уникальным IV. Заменить MD5/SHA-1 на SHA-256 или SHA-3. Обновить рекламные SDK до актуальных версий — большинство уязвимостей находится в сторонних библиотеках.
MEDIUM Экспортированные компоненты без защиты CWE-926
Описание
5 Activity, 3 Service, 6 Broadcast Receiver и 1 Content Provider помечены android:exported=true без требования разрешений. Доступны любому приложению на устройстве.
Риск
Стороннее приложение может запускать внутренние экраны, отправлять broadcast-события или читать данные Content Provider без авторизации.
Митигация
Для компонентов, не предназначенных для внешнего использования — установить android:exported=false. Для остальных — добавить android:permission с уровнем signature или signatureOrSystem.
MEDIUM Небезопасная реализация WebView (JavaScript Bridge) CWE-749
Описание
WebView используется с выполнением пользовательского JavaScript-кода. Найдено в Unity Ads, AppLovin, IronSource SDK.
Риск
XSS через рекламный контент может привести к выполнению произвольного кода в контексте приложения.
Митигация
Отключить setJavaScriptEnabled там, где JS не нужен. Валидировать URL перед загрузкой в WebView. Использовать @JavascriptInterface только для необходимых методов. Обновить SDK.
MEDIUM Хардкод чувствительных данных в коде CWE-312
Описание
MobSF обнаружил файлы с потенциально захардкоженными ключами, паролями или токенами в коде рекламных SDK.
Риск
APK может быть декомпилирован (jadx, apktool), что даст доступ к API-ключам рекламных платформ.
Митигация
Вынести чувствительные значения на сервер и получать их во время выполнения. Применить обфускацию (ProGuard/R8). Ротировать обнаруженные ключи. Использовать Android Keystore для хранения секретов.
MEDIUM Запись чувствительных данных в логи CWE-532 · MSTG-STORAGE-3
Описание
Приложение использует android.util.Log для записи информации. На рутованных устройствах или через ADB логи доступны другим приложениям.
Файлы
com/mbridge/, com/vungle/, com/fyber/inneractive/sdk/logger/
Митигация
Отключить все Log.d/Log.v в production-сборке через ProGuard-правила или флаг BuildConfig.DEBUG. Никогда не логировать токены, ID пользователей, ответы серверов с персональными данными.
