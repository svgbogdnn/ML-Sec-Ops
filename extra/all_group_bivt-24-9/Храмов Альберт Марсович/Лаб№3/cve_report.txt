Отчёт по CVE, связанным с уязвимостями REST API (OWASP Top 10 REST API)
Дата составления: апрель 2025 г.

========================================================================

CVE-1: CVE-2024-21733
========================================================================
Идентификатор: CVE-2024-21733
CVSS Score: 7.5 (High)
Продукт: Apache Tomcat (версии до 11.0.0-M2, 10.1.18, 9.0.85, 8.5.98)
Категория OWASP REST API: API3 — Broken Object Property Level Authorization
                          (ранее — Excessive Data Exposure)

Описание уязвимости:
Apache Tomcat при определённых условиях мог включать в HTTP-ответ данные
из предыдущего запроса другого пользователя. Это происходило из-за некорректной
обработки частичных HTTP/1.1 запросов (partial PUT). Сервер не очищал буфер
должным образом, и остаточные данные из чужого запроса могли попасть в ответ
следующему клиенту.

Причина:
Ошибка в логике управления буфером при обработке незавершённых PUT-запросов.
Сервер повторно использовал буфер без его полной очистки, что приводило к
утечке данных между сессиями.

Связь с REST API:
REST API, развёрнутые на Apache Tomcat, оказывались уязвимы к утечке данных
между запросами разных пользователей. Злоумышленник мог получить фрагменты
чужих запросов (заголовки, тело запроса с токенами или персональными данными).

Источник: https://nvd.nist.gov/vuln/detail/CVE-2024-21733

CVE-2: CVE-2024-23897
========================================================================
Идентификатор: CVE-2024-23897
CVSS Score: 9.8 (Critical)
Продукт: Jenkins (версии до 2.441 и LTS до 2.426.3)
Категория OWASP REST API: API8 — Security Misconfiguration

Описание уязвимости:
В Jenkins была обнаружена критическая уязвимость в CLI (Command Line Interface),
которая также затрагивала REST API. Встроенный парсер аргументов командной строки
(args4j) имел функцию расширения файловых аргументов: если аргумент начинался
с символа @, он интерпретировался как путь к файлу, содержимое которого
подставлялось вместо аргумента. Эта функция не была отключена, что позволяло
неаутентифицированным пользователям читать произвольные файлы с сервера Jenkins
через REST API эндпоинт /cli.

Причина:
Небезопасная конфигурация по умолчанию — опасная функция парсера аргументов
была включена и доступна через публичный API-эндпоинт без аутентификации.
Разработчики не ограничили доступ к CLI-эндпоинту и не отключили расширение
файловых аргументов.

Связь с REST API:
Уязвимость эксплуатировалась через REST API эндпоинт /cli. Атакующий отправлял
POST-запрос с аргументом вида @/etc/passwd и получал содержимое системных файлов
в ответе. При наличии прав на чтение можно было получить приватные ключи SSH,
секреты Jenkins и другие чувствительные данные.

Источник: https://nvd.nist.gov/vuln/detail/CVE-2024-23897

CVE-3: CVE-2024-27316
========================================================================
Идентификатор: CVE-2024-27316
CVSS Score: 7.5 (High)
Продукт: Apache httpd (версии 2.4.55 и ниже)
Категория OWASP REST API: API4 — Unrestricted Resource Consumption
                          (ранее — Lack of Resources & Rate Limiting)

Описание уязвимости:
В модуле mod_http2 веб-сервера Apache httpd была обнаружена уязвимость,
позволяющая проводить DoS-атаку (отказ в обслуживании). Злоумышленник мог
отправить специально сформированный HTTP/2 запрос с большим количеством
заголовков CONTINUATION, что приводило к чрезмерному потреблению памяти
сервером и его зависанию или падению. Атака получила название "HTTP/2
CONTINUATION Flood".

Причина:
Отсутствие ограничений на количество и суммарный размер CONTINUATION-фреймов
в одном HTTP/2 запросе. Сервер накапливал все фреймы в памяти перед обработкой,
не проверяя лимиты, что позволяло исчерпать доступную память.

Связь с REST API:
REST API, работающие поверх HTTP/2 (что является стандартом для современных API),
оказывались уязвимы к этой атаке. Злоумышленник без аутентификации мог вывести
из строя API-сервер, отправив один специально сформированный запрос, что
нарушало доступность сервиса для всех легитимных пользователей.

Источник: https://nvd.nist.gov/vuln/detail/CVE-2024-27316

- CVE-2024-27316: DoS через неограниченное потребление ресурсов (API4)
