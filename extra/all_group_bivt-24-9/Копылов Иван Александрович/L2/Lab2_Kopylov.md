## Часть 1
### [CVE-2026-3906](https://nvd.nist.gov/vuln/detail/CVE-2026-3906)
**Тип** : API5:2023 Broken Function Level Authorization (CWE-862 — Missing Authorisation)
**Описание:** В API появилась возможность делать редакторские "заметки на полях". При этом проверка пользователя проводилась только на предмет аутентификации, что давало возможность аутентифицированным читателям с недостаточным уровнем доступа (например, подписчика), создавать заметки на любом посте, включая посты от других пользователей и приватные посты.
**Ошибка**: Функция create_item_permissions_check() не проверяла, есть ли у пользователя разрешение на редактирование поста перед созданием заметки.
### [CVE-2026-40252](https://nvd.nist.gov/vuln/detail/CVE-2026-40252)
**Тип:** API1:2023 Broken Object Level Authorization (CWE-284, CWE-639)
**Описание:** FastGPT - платформа для создания AI Agent. Уязвимость позволяла любой аутентифицированной команде получать доступ и выполнять приложения, принадлежащие другим командам путем предоставления чужого appId. Это могло привести к разоблачению данных между клиентами.
**Ошибка:**  Хотя API-интерфейс правильно проверяет маркер команды, он не проверяет принадлежность запрошенного приложения проверенной команде.
### [CVE-2026-33146](https://nvd.nist.gov/vuln/detail/CVE-2026-33146)
**Тип:** API7:2023 Server Side Request Forgery (CWE-918)
**Описание:** в Keycloak, решении для управления удостоверениями и доступом, некорректно выполняется HTTP-переадресация при обработке определенных запросов клиентской конфигурации. Это поведение позволяет злоумышленнику обмануть сервер и заставить его сделать непреднамеренные запросы на внутренние или ограниченные ресурсы. Эта проблема может привести к раскрытию информации и дать возможность злоумышленникам составить карту внутренней сетевой инфраструктуры.
**Ошибка:** Небезопасная обработка HTTP-переадресации в пользовательских запросах.
