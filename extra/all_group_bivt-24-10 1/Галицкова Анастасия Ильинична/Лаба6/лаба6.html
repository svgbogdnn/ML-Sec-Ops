КРИТИЧНО Пароль в .env файле docker/.env · строки 3–4 
USER=alex675
PASSWORD=#!qerge34t423sdfvdsfgeR
Почему это секрет
Реальные логин и пароль, скорее всего от приватного репозитория пакетов. Высокая энтропия пароля говорит о том, что это не заглушка.
Как хранить правильно
Файл .env добавить в .gitignore. Значения передавать через GitHub Secrets / GitLab CI Variables или HashiCorp Vault.
КРИТИЧНО Приватный RSA-ключ webgoat-server/privatekey.key 
-----BEGIN PRIVATE KEY-----
MIIEvgIBADANBgkqhkiG9w0BAQEFAASC...
-----END PRIVATE KEY-----
Почему это секрет
Полный приватный RSA-ключ (2048-бит). Позволяет расшифровывать трафик и подделывать подписи. Остаётся в истории git навсегда.
Как хранить правильно
Только в Vault, HSM или AWS KMS. В репозиторий приватные ключи не должны попадать никогда.
КРИТИЧНО GitHub токен в workflows .github/workflows/release.yml · строка 75 
# было:
GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}

# стало:
GITHUB_TOKEN: cee3257f0e59d1d4975a35429cffc3d8b5fabe15...
Почему это секрет
Токен аутентификации GitHub захардкожен в файле вместо обращения к хранилищу секретов. Любой читатель репозитория получает доступ к аккаунту.
Как хранить правильно
Только через ${{ secrets.GITHUB_TOKEN }} или пользовательский секрет в Settings → Secrets репозитория.
ВЫСОКИЙ App Secret Key docker/.env · строка 2 
APP_SECRET=666666666666666
Почему это секрет
Ключ для подписи сессий и CSRF-токенов приложения. Значение слабое и предсказуемое — злоумышленник может подделывать сессии пользователей.
Как хранить правильно
Случайное значение длиной минимум 32 байта, хранить только в переменных окружения платформы, не коммитить.
СРЕДНИЙ CSR файл (PKI артефакт) webgoat-server/certificatesigningrequest.csr 
-----BEGIN CERTIFICATE REQUEST-----
MIIC4zCCAcsCAQAwdDEL...
-----END CERTIFICATE REQUEST-----
Почему это секрет
Пара к приватному ключу из секрета №2. Содержит метаданные организации, подтверждает связь с утёкшим ключом.
Как хранить правильно
Передавать напрямую в Certificate Authority через защищённый канал. В репозитории не хранить.
