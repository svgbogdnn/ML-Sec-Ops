Шаг 7 - проверка входа admin с новым паролем

Команда:
1) curl -X POST http://127.0.0.1:8080/users/v1/login -d '{"username":"admin","password":"pass1"}'
2) curl -X POST http://127.0.0.1:8080/users/v1/login -d '{"username":"admin","password":"newpass"}'
HTTP статус:
old password: 200; new password: 200
Ответ:
Старый пароль:
{ "status": "fail", "message": "Password is not correct for the given username."}

Новый пароль:
{"auth_token": "<auth_token admin>", "message": "Successfully logged in.", "status": "success"}
Вывод:
Старый пароль уже не подходит, а новый пароль дает успешный вход под admin. Уязвимость подтверждена.
