# Часть 1

### Проверка локальных образов
Смотрим какие образы уже есть командой `docker image ls` (image1.png)

В выводе находим скачанный ранее образ ket9/otus-devsecops-owasp-rest с тегом latest

### Пользователь на хосте
Далее смотрим юзера до запуска контейнера командой `whoami` - получил viacheslav (image2.png)

### Пользователь внутри контейнера
Запускаем командную оболочку sh внутри образа:
`docker run -it ket9/otus-devsecops-owasp-rest:latest sh`

Смотрим юзера командой `whoami` - получил root 

(image3.png)

# Часть 2

Создадим dockerfile для сборки нового безопасного образа на базе предыдущего

Далее билдим новый образ командой:
`docker build -t owasp-rest-secure:latest .` (image4.png)

Запускаем контейнер и сразу проваливаемся внутрь:
`docker run -it owasp-rest-secure:latest sh`

Снова проверяем пользователя внутри:
whoami

Вывод: appuser

(image5.png)

# Часть 3

Запускаем сканер безопасности на наш новый образ

docker run --rm \
  -v /var/run/docker.sock:/var/run/docker.sock \
  aquasec/trivy image owasp-rest-secure:latest

## Общий результат сканирования
Всего найдено 72 уязвимости

CRITICAL: 8

HIGH: 48

MEDIUM: 16

LOW: 0

## Примеры обнаруженных уязвимостей:

expat — CVE-2022-22822 (Уровень: CRITICAL).
Уязвимость переполнения целого числа (Integer overflow) в библиотеке синтаксического анализа XML. Может привести к выполнению произвольного кода или отказу в обслуживании

busybox — CVE-2021-42378 (Уровень: HIGH).
Уязвимость использования памяти после освобождения (use-after-free) в апплете awk. Также ведет к риску отказа в обслуживании

## Выводы по безопасности образа

В ходе сканирования Trivy выдал предупреждение о том, что базовая операционная система образа (Alpine 3.14.2) устарела и больше не поддерживается разработчиками (This OS version is no longer supported)

Все найденные критические (CRITICAL) и высокие (HIGH) уязвимости относятся именно к системным утилитам и библиотекам старого дистрибутива, а не к коду самого приложения

Меры предотвращения: изменить базовый образ в dockerfile на актуальную и поддерживаемую версию (например, alpine:3.19 или новее), после чего заново пересобрать контейнер
