Файл был скачан с APKPure: https://apkpure.net/clash-of-clans-android-app/com.supercell.clashofclans/download

MobSF запускал через Docker

Запуск MobSF

MobSF был запущен в Docker. После запуска я открыл веб-интерфейс MobSF в браузере и загрузил туда APK-файл.

После загрузки MobSF сам провёл статический анализ приложения и показал отчёт.

Найденные проблемы

1. Dangerous permissions

MobSF показал 2 dangerous permission:

android.permission.POST_NOTIFICATIONS

android.permission.CAMERA

POST_NOTIFICATIONS - это разрешение на уведомления. Для игры это нормально, но всё равно такое разрешение должно быть понятно пользователю. CAMERA - это уже более чувствительное разрешение, потому что приложение получает доступ к камере телефона. Даже если оно нужно для какой-то функции, его лучше запрашивать только тогда, когда пользователь реально использует эту функцию.

Проверить, действительно ли приложению нужна камера. Если не нужна — убрать разрешение из манифеста. Если нужна - запрашивать его только при использовании функции.

2. Cleartext traffic

В отчёте MobSF было найдено:

Clear text traffic is Enabled For App [android:usesCleartextTraffic=true]

Это значит, что приложение разрешает незашифрованный трафик.

Если приложение использует HTTP вместо HTTPS, данные могут быть перехвачены или изменены в сети.

Отключить cleartext traffic:

android:usesCleartextTraffic="false"

Также нужно проверить network security config и использовать только HTTPS.

3. Старая версия Android

MobSF показал:

App can be installed on a vulnerable unpatched Android version 7.0, [minSdk=24]

То есть приложение можно установить на Android 7.0. Такая версия Android уже старая и может не получать обновления безопасности. На старых версиях Android могут быть уязвимости, которые уже не исправляются. По возможности поднять minSdkVersion на более новую версию Android.

4. Алгоритм подписи SHA1

MobSF также нашёл проблему:

Certificate algorithm vulnerable to hash collision

В отчёте указано, что используется:

SHA1withRSA

SHA-1 считается устаревшим алгоритмом. Сейчас его лучше не использовать. Проверить подпись приложения и использовать более современный алгоритм подписи.

5. Privacy trackers

MobSF нашёл несколько privacy trackers:

AppsFlyer

Google Firebase Analytics

HelpShift

Sentry

Snowplow

Для игры это может быть нормально, потому что используются аналитика, ошибки и реклама. Но всё равно это связано со сбором данных пользователя.

Проверить, какие SDK реально нужны. Ненужные удалить, остальные обновить до актуальных версий. Также нужно, чтобы в политике конфиденциальности было понятно описано, какие данные собираются.

Code Analysis

В разделе Code Analysis для этого APK MobSF не показал high findings. То есть основные проблемы были не в коде, а в настройках приложения, разрешениях, сетевой безопасности и подписи.

План митигации

  1. Отключить cleartext traffic и использовать только HTTPS.

  2. Проверить dangerous permissions, особенно CAMERA.

  3. Если камера не нужна — удалить разрешение.

  4. Поднять минимальную версию Android, если это возможно.

  5. Обновить алгоритм подписи, не использовать SHA-1.

  6. Проверить сторонние SDK и privacy trackers.

  7. Удалить лишние SDK и обновить нужные.

  8. Повторно просканировать APK в MobSF после исправлений.

Вывод

В ходе работы развернул MobSF через Docker и проверил APK приложения Clash of Clans.

MobSF показал Security Score 38/100. В приложении были найдены проблемы: dangerous permissions, разрешённый cleartext traffic, поддержка старой версии Android, устаревший алгоритм SHA1withRSA и privacy trackers.

Главные рекомендации: отключить HTTP-трафик, использовать HTTPS, пересмотреть разрешения, обновить подпись приложения и проверить сторонние SDK.
